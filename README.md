# OpenVortex for Fluid Dynamics Post-Processing

A Python toolkit for characterizing vortex cores and centerlines in 3D CFD and PIV data with the
**Adaptive Centerline Interpolation (ACI)** method.

## Status: pre-release

The source code is not public yet. It will be released here together with the
accompanying paper.

To be notified when it is released, click **Watch → Custom → Releases** at the top of
this page. Starring the repository alone does not send notifications.
